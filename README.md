# JailBreakBERT
## Detection of Jailbreaking Prompts in Large Language Models

Download [Fine-Tuned GPT Model](https://drive.google.com/file/d/1k2F2TVdPMG4df8BA1e2lekYHugp3zhR3/view?usp=sharing) to generate synthetic toxic/jailbreaking prompts.\
Download [JailBreakBERT Model](https://drive.google.com/uc?export=download&id=1cwQfIAN7_3Yt_jcYjlB3n4Tot2JTTRC2) and [JailBreakRoBERTa Model](https://drive.google.com/file/d/1Y2H_ZbAv6Vs7Z0eaVDhMztujZOZz-sIS/view?usp=sharing) to classify the prompt whether it is regular or toxic.
